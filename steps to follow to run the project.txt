steps to follow to run the project :

1) download and extract the zip folder

2) open that extracted folder in vs-code 

3) make sure to check database credentials in settings.py

4) create database manually in MySQL with db name : edutrackpython 

5) also add the user in table { firstly you have to run migrate command, then tables will be created}

3) open the terminal - 2 terminal - 

     ** commands ** 
   
  ----  1st terminal -----

   a) npm install

   b) for UI - npm run dev

 ----  2st terminal -----

   a) cd backend

   b) for backend : py -m pip install -r requirements.txt

   c) to add tables : py manage.py migrate

   d) run the project : py manage.py runserver 8092
